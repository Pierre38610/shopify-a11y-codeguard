Pourquoi les widgets overlay échouent aux tests clavier

Ce que fait un widget overlay

  • Ajoute une barre d’outils cosmétique par-dessus le thème existant.
  • Ne corrige pas les balises <div> non focusables dans product-variant-picker.liquid.
  • Ne résout pas les pièges clavier dans le tiroir panier ou les popups tierces.
  • Alourdit le storefront via un script externe facturé chaque mois.

Notre approche Code Source Liquid/CSS

  • Audit automatisé Playwright simulant un acheteur 100 % clavier (Tab, Enter, Escape).
  • Preuves visuelles irréfutables : captures annotées + clip vidéo du blocage exact.
  • Séparation transparente : Code Thème Liquid vs Applications Tierces (tickets support prêts à envoyer).
  • Registre horodaté des audits et correctifs appliqués.
